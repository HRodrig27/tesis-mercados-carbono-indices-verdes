# Datos

Los datos originales utilizados en la tesis fueron obtenidos de Bloomberg y no se distribuyen en este repositorio.

Para reproducir los códigos, el archivo de entrada debe contener una columna `FECHA` y las siguientes series:

## Índices verdes
- ECO Index
- GRNBIO Index
- GRNREG Index
- GRNGEO Index
- GRNFUEL Index
- GRNSOLAR Index
- GRNWIND Index

## Mercados de carbono
- EEXXT3PA Index — EU ETS
- CNNCGDEP Index — Guangdong
- CNNCHBEP Index — Hubei
- CNNCSZEP Index — Shenzhen

Periodo utilizado en la investigación: 3 de enero de 2018 a 31 de mayo de 2024.
